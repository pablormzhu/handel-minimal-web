## Criterio

- Se inspeccionó el archivo final que devuelve `productImage`, no solo la existencia del SKU.
- “Correcto conservado” significa fotografía local real con producto/presentación legibles y equivalencia revisada; no implica que el archivo haya sido descargado hoy del fabricante.
- “Reconstruido con referencia” identifica explícitamente un activo de catálogo no oficial cuya rotulación principal sí se puede leer.
- “Pendiente fuente” se usa cuando falta una fotografía pública inequívoca de esa combinación de nombre, generación, capacidad y presentación.
- `2G` se trata como segunda generación, nunca como gramos; `50/100 pruebas` es capacidad del kit.
- Fondos, objetos, etiquetas, catálogo, copy y layouts no se alteraron en esta corrección.
